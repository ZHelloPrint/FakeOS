# CSOS - Futuristic Browser-Based Operating System

**CSOS** is a highly polished, modular, and animated browser-based operating system designed to emulate a real desktop OS within a web browser. It features a futuristic, bubbly UI with smooth animations, window management, a virtual filesystem, customizable wallpapers, applications, and more.

## Features

- Full-screen desktop environment with system bar, bottom dock, and icons
- Boot sequence with animated loading
- Lock screen with smooth unlock animation
- Customizable desktop wallpaper (including GIF wallpapers)
- Virtual filesystem stored in localStorage/IndexedDB
- Window management with drag, resize, minimize, maximize, focus
- Built-in applications: Browser, Calculator, Notes, Paint, Terminal, Settings, About
- Browser with tabs, DuckDuckGo search, bookmarks, history
- Media support and embedded YouTube videos
- Custom Web pages and widgets
- Modular architecture for future expansion: themes, wallpapers, store, modules

## Tech Stack

- HTML, CSS, JavaScript
- Uses Web APIs: localStorage, IndexedDB, Canvas, SVG
- No backend required, suitable for hosting on GitHub Pages

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Edge, Safari)
- Basic knowledge of running local files or hosting on GitHub Pages

### Running Locally

1. Clone or download this repository
2. Open `index.html` in your web browser

### Hosting on GitHub Pages

1. Push the project to a GitHub repository
2. Enable GitHub Pages in the repository settings (select main branch or /docs folder)
3. Access your CSOS instance via the provided URL

## Usage

- The desktop loads with a boot animation
- Use icons and the dock to launch applications
- Customize wallpaper, themes in Settings app
- Lock/unlock via the lock screen
- Manage files and folders in the virtual filesystem
- Expand functionality by adding new apps or modules

## Customization & Development

- Modify `js/` files to add new applications
- Extend the virtual filesystem by enhancing `localStorage` or `IndexedDB`
- Change themes and wallpapers through the Settings app
- Enhance animations with CSS or JavaScript
